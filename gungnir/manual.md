# 궁니르 사용 매뉴얼

궁니르(Gungnir)는 IP 콜라보 제안서를 작성하고, 콜라보할 IP를 찾는(소싱) 시스템입니다. 이름은 북유럽 신화에서 오딘이 던지면 반드시 과녁에 꽂히는 창에서 따왔습니다. IP를 입력하면 리서치·제안서 원고·디자인·이미지 수급은 판테온 봇이 진행하고, 담당자는 중간의 **결정 단계**에서만 선택하고 확인하면 됩니다.

- 접속 주소: thealmightycorp.github.io/pantheon/gungnir
- 로그인: 헤임달 계정(회사 이메일과 비밀번호)
- 회사·IP·담당자 정보는 **이그드라실**(왼쪽 메뉴 「이그드라실 ↗」)에 등록되어 있고, 궁니르는 이 정보를 불러와 사용합니다.

각 장은 따로 읽어도 이해할 수 있도록 작성했습니다. 장마다 첫 줄의 「대상」을 보고 해당하는 부분부터 읽으시면 됩니다. 궁금한 점은 이 화면 위쪽 **매뉴얼에 물어보기**에 입력하시면 매뉴얼 내용으로 바로 답해 드립니다.

## 1. 시작하기 (로그인·비밀번호·로그아웃)

대상: 궁니르 권한이 있는 직원

궁니르는 헤임달(회의록 시스템)·이그드라실과 같은 계정을 사용합니다. 현재 시험 운영 중이라 권한을 받은 직원만 이용할 수 있습니다.

### 처음 사용하는 분 (헤임달 가입)

1. 브라우저에서 route82.github.io/heimdall 에 접속합니다.
2. **가입** 탭을 누르고 회사 이메일, 비밀번호(6자 이상), 이름, 소속 회사, 부서를 입력합니다.
3. **가입하고 시작하기**를 누릅니다.
4. 관리자가 승인하면 사용할 수 있습니다. 궁니르 권한은 AX팀이 별도로 부여합니다.

### 로그인

1. thealmightycorp.github.io/pantheon/gungnir 에 접속합니다.
2. 헤임달과 같은 이메일과 비밀번호를 입력하고 **로그인**을 누릅니다.
3. 헤임달이나 이그드라실에 이미 로그인한 브라우저에서는 로그인 화면 없이 바로 열립니다.

### 비밀번호를 잊었을 때

1. 로그인 화면에 이메일을 먼저 입력합니다.
2. **비밀번호를 잊으셨나요? 비밀번호 찾기**를 누릅니다.
3. 메일로 받은 링크를 누르고 새 비밀번호(8자 이상)를 두 번 입력합니다.
4. 헤임달·이그드라실 비밀번호도 함께 변경됩니다.

### 알아 두실 점

- 「제안서 스튜디오는 시험 기간이라 일부 직원만 쓸 수 있습니다」라는 안내가 나오면 아직 궁니르 권한이 없는 상태입니다. AX팀에 요청하세요.
- 로그아웃: 왼쪽 아래 내 이름을 누르고 **로그아웃**을 누릅니다. 헤임달·이그드라실에서도 함께 로그아웃됩니다.

## 2. 화면 구성

대상: 궁니르 권한이 있는 직원

- **왼쪽 메뉴**: 제안서 스튜디오 · **소싱 · IP 차트**(권한이 있는 분만) · 사용 매뉴얼 · 이그드라실 ↗이 있습니다.
- **제안서 스튜디오 위쪽 탭**: **프로젝트**(제안서 목록) · **레퍼런스 라이브러리**(제안서 양식 견본) · **이미지 아카이브**(지금까지 사용한 이미지)가 있습니다.
- **숫자 카드**: 진행 중 · 결정 대기(내가 확인할 차례) · 판테온 봇 처리 중 · 완료 건수를 보여 줍니다.
- **전체 프로젝트 표**: 열 제목을 누르면 정렬되고, 「기안자 전체」에서 기안자별로 필터링할 수 있습니다.
- **지금 결정할 항목**: 항목을 누르면 해당 프로젝트의 결정 화면이 바로 열립니다.

## 3. 새 제안서 작성

대상: 궁니르 권한이 있는 직원

오른쪽 위 **+ 새 프로젝트**를 누르고 아래 항목을 입력한 뒤 **프로젝트 생성**을 누릅니다.

| 항목 | 입력 방법 |
|---|---|
| IP (필수) | 제안의 중심이 되는 IP. 예: 에스파. 이그드라실에 등록된 이름을 선택하면 담당자·연락처가 함께 연결됩니다. 등록되지 않은 이름도 그대로 진행할 수 있습니다. |
| 제안 방식 | **콜라보 제안**(IP A × IP B) 또는 **단독 제안**(IP 하나) |
| 파트너 IP | 콜라보 상대. **비워 두면 판테온 봇이 후보를 추천**합니다. |
| 수신사 | 제안서를 받을 회사. 예: SM엔터테인먼트 |
| 레퍼런스 포맷 | 제안서 양식 견본. 보통 「(기본)」을 그대로 사용합니다. |
| 강조색 | 「클로드 추천」을 선택하면 컨셉에 맞춰 자동으로 정합니다. 생성 후에도 변경할 수 있습니다. |
| 메모 | 참고 사항. 예: 최초 제안 · 팝업 중심 |

수신사·레퍼런스·강조색·메모는 프로젝트 화면 오른쪽 「기본 정보」의 **수정**에서 언제든 변경할 수 있습니다. IP·제안 방식·파트너 IP는 리서치가 시작되면 변경할 수 없습니다.

## 4. 진행 단계

대상: 궁니르 권한이 있는 직원

프로젝트를 누르면 위쪽에 8단계 진행 표시가 나옵니다. **결정** 단계는 담당자가 선택할 차례이고, 나머지 단계는 판테온 봇이 자동으로 진행합니다.

| 단계 | 담당 | 내용 |
|---|---|---|
| 1 IP 입력 | 담당자 | 새 프로젝트 생성 |
| 2 기본 정보 | 결정 | IP·수신사·포맷을 확인하고 확정 |
| 3 파트너 IP 추천 | 결정 | 추천 카드 중 하나를 선택하거나, 「직접 입력」에 원하는 IP를 입력하고 「이 IP로 진행」. 점수는 1~5점이며 **리스크 점수는 높을수록 위험**합니다. 마음에 드는 후보가 없으면 「카테고리 변경 후 재추천」. 단독 제안은 이 단계를 건너뜁니다. |
| 4 리서치 | 봇 | 두 IP의 팬층·트렌드·최근 이슈·공식 채널 조사 |
| 5 컨셉 설계 | 결정 | 컨셉 후보 중 하나를 확정 |
| 6 제안서 생성 | 봇 | 원고와 페이지 디자인 작성. 이미지 위치는 회색 상자로 비워 둡니다. |
| 7 이미지 계획 | 결정 | 공식 이미지는 자동으로 찾고, AI로 생성해야 하는 이미지는 예상 비용을 확인한 뒤 「승인 후 생성」 |
| 8 생성·삽입·검수 | 결정 | 검수에서 지적된 부분을 확인하고 「이 버전으로 완료」 |

- 판테온 봇이 작업하는 동안에는 진행률과 현재 작업 내용이 표시됩니다.
- **화면을 닫거나 새로 고침해도 작업은 계속 진행됩니다.** 결정할 차례가 되면 「지금 결정할 항목」에 표시됩니다.

## 5. 제안서 확인·수정

대상: 궁니르 권한이 있는 직원

### 초안 확인과 다운로드

- **PDF 보기** · **PPTX 다운로드**: 현재 버전을 바로 확인하거나 다운로드합니다.
- **이미지 확인·수정**: 제안서를 페이지별로 넘겨 보며 수정합니다.
- 강조색은 색을 선택하고 **이 색으로 적용**을 누르면 변경됩니다.

### 이미지 수정

- 페이지에서 이미지를 누르면 **교체 · 위치 조정 · 다시 생성**을 할 수 있습니다.
- 새로 생성한 이미지가 마음에 들면 **이 이미지로 확정**을, 아니면 **새 이미지 버리기**를 누릅니다.
- 이미지는 드래그해서 위치를 옮긴 뒤 **위치 저장**을 누릅니다. 글자 위치는 **글자 위치 옮기기**에서 조정합니다.
- 수정을 마쳤으면 **변경 사항 반영**을 누르고, 결과를 확인한 뒤 **이 버전으로 완료**를 누릅니다.

### 원고 수정

- 진행 중: 「원고 수정 요청」을 열어 수정할 내용을 입력하고 **v2 만들기**를 누릅니다. 예: 「앞쪽 팬 반응 페이지를 빼고 콜라보 명분을 더 강하게」
- 완료 후: 수신사 피드백을 「수정 버전 만들기」에 입력하면 다음 버전을 작성합니다. 새로 필요한 이미지만 다시 수급합니다.
- 같은 IP로 다른 컨셉의 제안서도 보고 싶으면 **+ 같은 IP로 다른 컨셉 제안서 생성**을 누릅니다.

## 6. 작업 중지와 재시작

대상: 궁니르 권한이 있는 직원

- **작업 취소**: 진행 중인 작업을 중지합니다. 이미 작성된 결과는 그대로 남습니다.
- **○○ 다시 시작**: 취소한 작업을 이어서 진행합니다.
- **다시 시도**: 「작업 실패」가 표시되면 누릅니다. 계속 실패하면 AX팀 김현우에게 알려 주세요.

## 7. 소싱 · IP 차트

대상: 소싱 권한이 있는 직원 (현재 일부 직원)

콜라보할 IP를 찾고 점수로 비교하는 화면입니다. 메뉴가 보이지 않으면 권한이 없는 상태입니다.

- **IP 차트**: 웹에서 수집한 IP의 순위를 하루 4번 갱신합니다. **신규 / 전체** 차트와 기간(실시간·일간·주간·월간·연간·기간 설정), 종류별로 볼 수 있습니다. IP를 누르면 인기 상승 이유, 트렌드, 최근 이슈, 순위 추이, 공식 문의처가 표시됩니다.
- **IP 스코어**: IP마다 타이밍·팬덤·관계 점수를 합산한 점수입니다. 관계 점수는 해당 IP 권리사와의 접촉 기록이 많을수록 올라갑니다.
- **IP 직접 추가**: 차트에 없는 IP의 이름·영문 이름·종류·권리사를 입력하면 판테온 봇이 몇 분 이내에 일정을 찾아 점수를 계산하고, 요청하면 조합까지 만듭니다.
- **조합**: 두 IP를 묶었을 때의 점수와, 성사를 위해 확보해야 할 연락 경로를 보여 줍니다.
- **워닝·감시**: 조합 점수가 기준을 넘거나 감시 조건(예: 새 일정 발표)에 해당하면 워닝으로 알려 줍니다. 같은 조합은 7일에 한 번만 알립니다.
- **수집 소스**: 팬덤 반응을 수집하는 사이트 목록과 점검 결과를 보여 줍니다.
- 차트에 새로 등장한 IP는 이그드라실 확인 대기에 후보로 등록됩니다.

## 8. 참고 사항

대상: 궁니르 권한이 있는 직원

- 리서치가 시작된 뒤에는 IP와 제안 방식을 변경할 수 없습니다. 다른 IP로 진행하려면 새 프로젝트를 만듭니다.
- 같은 IP 조합·수신사로 작성한 제안서는 「제안서 1 · 2 · 3」으로 함께 표시됩니다.
- AI 이미지는 승인한 것만 생성하며, 생성에 실패했거나 부적절한 이미지는 비용이 청구되지 않습니다.
- IP·회사 정보가 잘못됐거나 없으면 이그드라실에서 수정하거나 등록하세요. 다음 제안서부터 반영됩니다.
- 완료된 제안서의 리서치 내용 중 출처가 있는 정보는 이그드라실 위키 초안으로 정리됩니다(확인 후 반영).

## 9. 자주 묻는 질문

**Q1. 궁니르 비밀번호는 어디서 만드나요?**
A. 별도 비밀번호는 없습니다. 헤임달 비밀번호와 같습니다. 잊으셨다면 로그인 화면의 비밀번호 찾기를 이용하세요.

**Q2. 로그인했는데 「시험 기간이라 일부 직원만」이라는 안내가 나와요.**
A. 아직 궁니르 권한이 없는 상태입니다. AX팀에 요청하세요.

**Q3. 파트너 추천이 마음에 들지 않아요.**
A. 3단계에서 「직접 입력」에 원하는 IP를 입력하고 「이 IP로 진행」을 누르거나, 「카테고리 변경 후 재추천」을 누르세요.

**Q4. 작업이 너무 오래 걸려요.**
A. 리서치와 제안서 생성은 수십 분이 걸릴 수 있습니다. 화면을 닫아도 작업은 계속 진행되고, 결정할 차례가 되면 「지금 결정할 항목」에 표시됩니다.

**Q5. 실수로 작업 취소를 눌렀어요.**
A. 결정 카드의 「○○ 다시 시작」을 누르면 이어서 진행합니다.

**Q6. 수신사를 잘못 입력했어요.**
A. 프로젝트 화면 오른쪽 「기본 정보」의 수정에서 변경하세요. 수신사·레퍼런스·강조색·메모는 언제든 변경할 수 있습니다.

**Q7. 제안서를 파워포인트 파일로 받을 수 있나요?**
A. 네. 프로젝트 화면의 PPTX 다운로드를 누르세요.

**Q8. AI 이미지 비용은 얼마나 드나요?**
A. 7단계에서 이미지별 예상 비용을 보여 드립니다. 승인한 이미지만 생성하며, 생성에 실패한 이미지는 비용이 청구되지 않습니다.

**Q9. 소싱 · IP 차트 메뉴가 보이지 않아요.**
A. 현재 일부 직원만 볼 수 있습니다. 필요하면 AX팀에 요청하세요.

**Q10. 휴대폰에서도 사용할 수 있나요?**
A. 확인과 결정은 휴대폰에서도 할 수 있습니다. 이미지 위치 조정처럼 세밀한 작업은 PC 사용을 권장합니다.
